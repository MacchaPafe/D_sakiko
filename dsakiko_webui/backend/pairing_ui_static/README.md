# 配对连接 UI 界面

该界面是程序启动后自动显示的配对页面，可以扫描其中生成的二维码，在手机端直接连接电脑侧服务器，无需手动输入网址或者输入访问认证码。

因为该页面包含可以直接用于连接后端的凭据（一个随机字符串认证码），绝对不能暴露在可被外部设备访问的端口，因此将其放在后端页面，实现和前端的物理隔离，
确保不会发布到公共网络上。

> 此外，该页面只是个简单的 html+js+css 静态页面，没有任何框架，所以和前端分离从技术上是可行的。

该页面绑定 127.0.0.1 回环地址的随机端口，因此只有本机运行的程序可以访问，只有本机浏览器可见。

> 相对的，前端绑定的 IP 地址为 0.0.0.0，该地址为一个虚拟地址（是任何设备都无法真正持有的 IP），表示该设备自身在所有网卡上的所有 IP 地址。
> 
> 因此，绑定在该地址后，前端在该设备接入的任何网络上都可以访问。例如，设备同时接入 Wi-Fi 和有线网络，那么该页面在两个 IP 上都能被看到。
