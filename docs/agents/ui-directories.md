# 桌面 UI 目录边界

`GPT_SoVITS/` 下的桌面界面按所属界面和控件体系组织：

| 目录 | 职责 |
| --- | --- |
| `ui_fluent_widget/` | qfluentwidgets 构建的配置、角色管理、世界书管理页面，以及它们专属的自定义控件、控制器和检测线程。 |
| `ui_qt/` | 主聊天窗口组件、上下文用量弹窗、更新及修复界面、桌宠复用的输入组件，以及跨界面共享的主题和 Qt 辅助能力。 |
| `ui_motion_editor/` | 原生 Qt 构建的 Live2D 动作组、表情、面具动作编辑器及查看器辅助组件。 |
| `ui_small_theater/` | 原生 Qt 构建的小剧场编排器、时间轴、台词弹窗、菜单、窗口布局和专属样式。 |

- `ui_fluent_widget` 允许组合普通 Qt 控件，归属按页面的控件及样式体系判断。
- `ui_qt` 的主题、文件管理器定位等共享能力可以被其他界面使用；组件内部不反向导入具体 Fluent 页面。
- 小剧场可以复用动作编辑器、BGM 弹窗等已有能力，不复制业务实现。
- 页面专属控制器和线程跟随所属页面；Live2D 底层模型、动作及播放能力仍在 `live2d_support/`。
- `components/` 放业务组件，`custom_widgets/` 放通用控件，`interfaces/` 放完整页面，`styles/` 放专属样式。
- 包的 `__init__.py` 保持轻量，不集中导入窗口或为旧包名建立兼容别名。
- 移动文件时同时核对函数内延迟导入、测试 patch 字符串及通过 `__file__` 定位的资源；不要顺带修改业务行为。
- 新路径必须加入 Git 跟踪后再使用默认发布配置构建补丁。更新清单按旧文件删除、新文件新增表达迁移，发布前应核对删除清单并在旧版副本上安装验证。
