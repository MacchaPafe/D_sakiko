# 按世界书包依赖限定检索范围

官方世界书包按动画季度划分，共享世界观进入独立通用包；每条索引记录携带来源 `package_id`，运行时只检索对话选择的单个根包及其依赖闭包，Lore 的包范围语义也只在该集合内成立。参与同一对话检索的依赖包必须与根包共享 `timeline_id`，但依赖解析本身不要求 `canon_branch` 一致，具体条目仍按当前对话的剧情分支过滤；不同时间轴的 crossover 需要先定义统一时间轴和明确的组合根包，不能靠同时选择多个根包或直接比较内部时间整数实现。所有已安装包可以统一进入索引，对话切换不触发重建；相比按品牌、`series_id` 或 `canon_branch` 推断范围，这要求显式维护依赖，却能隔离世界关系尚未确认的作品，并允许以后通过调整依赖表达新的官方信息。
