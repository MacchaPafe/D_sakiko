# 隔离 ChatGPT 订阅路由与账户生命周期

已接受，2026-11-08。后续于 [ADR-0050](0050-unify-python-generation-and-conversation-timeline.md) 增加 OAuth，不改变共同对话时间线或统一生成入口。

## 决定

将“协议”和“路由”分开：ChatGPT 订阅与 API Key 均使用公共 Responses；订阅的受限参数、工具封装和模型能力检查集中于 llm/response_routes.py。响应编解码、历史投影和完整 SSE 判定共用 llm/adapters/responses.py，不复制一个订阅版 Responses 实现。

功能要求不自动删除；仅明确不支持的生成偏好在请求副本中省略，返回诊断。extra_body 也经过同一次校验。UI 复用同一个路由规则展示限制。能力来源分为固定路由契约、当前账户模型目录的明确声明及服务端实际错误；不使用其他账户或 API Key 模型目录推断订阅能力。

原生浏览器 OAuth、签名验证、注册身份、跨进程令牌刷新和凭据存储属于 llm/chatgpt/。业务调用方只提供连接快照、完整上下文及取消信号，取得完整结果或统一错误。关联请求头和一次性认证恢复仅由订阅 runtime 处理；额度、权限和断流错误不触发自动换账户或计费路径。

## 账户与界面

Fluent 配置支持多个注册、一个活动账户和一个跨账户复用的全局模型。统一登录按钮在选择已保存账户时复用注册，选择“添加其他账户”时创建注册；仅提供退出登录，始终保留账户映射、Client ID 与 Host ID，不提供独立重新登录或移除操作。登录立即持久化；添加成功自动激活新账户，首次模型须手选，后续账户沿用全局模型。已验证账户和模型选择自动保存，待登录选择必须完成 OAuth 验证后才替换活动账户，不顺带保存无关配置草稿。本轮采用原有快照，修改从下一轮生效；账户使用租约阻止生成期间退出。

系统凭据库写入失败允许静默降级到私有文件，并保存权威位置，避免恢复钥匙串后读取已轮换的旧令牌。普通配置和历史只保存非秘密引用。模型目录单独缓存，损坏可重建，注册身份损坏则明确报错。

## 代价与验证

路由策略需要随官方预览限制更新，但修改集中于一处。真实账户和 Windows 凭据权限需对应平台验证；模拟测试不能证明服务端已向特定账户开放接入。

详细流程及验证范围见 [设计说明](../design/python-unified-llm.md#chatgpt-订阅接入)。
