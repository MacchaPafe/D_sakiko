# 由各渲染器分别表达无模型状态

无模型展示继续遵循 ADR-0003 的 seam：共享 Live2D 支持模块只统一严格模型加载、目标加载结果和可选 runtime 的底层生命周期，不接管音频、字幕、布局或槽位业务状态。单角色渲染器使用返回动作失败的 Null model 来适配其按必有模型编写的主循环，小剧场则沿用可空模型槽位；两者采用不同表达，是因为小剧场现有播放与逐帧路径已经把空槽作为正常状态，而强行统一会扩大共享接口并混入渲染器特有规则。

没有可绘制模型时，OpenGL 窗口、背景和字幕继续存在，但不初始化 Live2D runtime；从有模型切换到无模型时释放模型和 runtime，从无模型切换到模型时按目标版本初始化 runtime。小剧场只有一个可绘制模型时使用该模型的 runtime，两个槽位都无模型时不初始化 runtime；空模型槽位不产生版本不一致提示，也不影响另一槽继续演出。
