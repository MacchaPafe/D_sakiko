# 用 PACKAGE 取代容易误解的 GLOBAL Lore 范围

在尚未发布的世界书条目 schema 中，将 Lore 的 `scope_type: GLOBAL` 重命名为 `PACKAGE`，不保留旧值兼容。`PACKAGE` 表示条目在其所属包作为当前根包或进入根包依赖闭包时可见，仍须通过时间轴、剧情分支、有效时间和可空学年过滤；它不表示数据库全局、品牌全局或所有动画作品均可见。`SERIES` 继续表示只有当前对话根包的 `series_id` 命中条目的 `series_ids` 时才可见，因此依赖包中的 `SERIES` 条目不会自然传递到后续季度。跨季度真正共享的独立内容仍可放入通用依赖包，`PACKAGE` 与通用包分别表达条目适用范围和内容所有权，不互相替代。

自动标注导入无法可靠判断一条 Lore 是长期世界观还是当季状态，因此继续保守地默认 `SERIES` 并填入当前 `series_id`；审核者必须显式将适合由依赖作品继承的条目提升为 `PACKAGE`。用户已经选择目标世界书包后手工新增的 Lore 则默认 `PACKAGE`。Stage 3 数据集编辑器和审核工作台都使用带说明的受控范围选择，不再要求编辑者输入裸枚举字符串：`SERIES` 显示可编辑的适用作品列表，`PACKAGE` 隐藏并清空该列表，审核完成即表示审核者确认当前范围，不为此增加独立的 `scope_reviewed` 字段。

现有正式 MyGO 包中的十三条 Lore 保持原有 `SERIES` 值，本次运行时接入不批量改写，也不以范围复核作为阻塞条件；内容维护者之后按条人工复核，任何范围修改沿用现有内容变更后撤销旧审批并重新审核的流程。
