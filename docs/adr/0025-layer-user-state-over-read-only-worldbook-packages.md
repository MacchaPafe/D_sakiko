# 在只读官方世界书包上叠加用户状态

官方包保持只读，每个包对应一份独立用户状态，完整保存保留原身份与类型的 Override、归属于该包的用户扩展和隐藏官方条目的 tombstone，并由两层合并出有效条目。有效 Override 即使官方基础变化仍继续生效并提示复核，无法验证或投影的不兼容 Override 只隔离对应条目且不静默回退；官方条目只能隐藏和恢复，删除 Override 表示恢复官方版本，只有用户扩展可以永久删除。相比直接修改官方 JSON 或字段级补丁，这个模型需要冲突界面和合并逻辑，但能让应用更新尊重用户修改并保持稳定身份。

用户扩展只能从当前直接选中的所属世界书创建和编辑；通过依赖闭包看到的其他包扩展保持只读，并引导用户切换到所属包。新建扩展由程序分配 entry UUID 以及 Thought Thread 或 Relation Type UUID，沿用官方条目的类型校验和包内时间线；检索文本留空时使用各 Type Module 的透明基础文本。永久删除剧情事件前必须扫描全部已安装包的官方、Override、用户扩展与隐藏内容并展示完整影响预览：当前所属包中能够安全写回的角色想法只移除目标事件引用并保留正文，纯官方想法通过完整 Override 表达，孤立或不兼容且无法安全改写的用户内容在明确确认后整体删除；其他包引用继续阻断删除并引导用户切换所属包。当前包内的目标事件和全部连带用户状态通过一次原子保存提交，任何预检或写入失败都不执行部分变更；索引同步失败不回滚已经保存的用户状态。
