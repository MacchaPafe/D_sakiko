# 通过直接上下文与静默工具共同提供世界书知识

世界书检索范围由应用持有，模型只接收与本轮相关的 Character Thought、知识使用规则以及静默世界书工具结果；Lore、角色关系和进一步的角色剧情记忆由独立于通用工具开关的世界书工具主动检索。记忆工具返回 Thought 时总是展开其仍在剧情进度内的全部显式关联 Story Event，仅提供事件标题、审核摘要和参与者等正文信息，不把用于搜索的 `retrieval_text`、排序重要度或内部时间范围冒充剧情内容。语义检索以向量相似度为主，并对查询中精确出现的规范标题或标签作轻量排序加权；直接 Thought 使用较严格阈值，工具查询也拒绝低于最低阈值的噪声结果，阈值只通过诊断校准而不成为普通用户设置。关系工具以动态枚举的规范 Character ID 接收目标角色；该枚举只从当前视角、当前剧情进度已经开始且仍在有效索引中的 Relation 派生，并在单回合工具注册时冻结，枚举查询失败或为空时本轮不注册关系工具。工具结果保留审核原文和知识状态而不自动改写成第一人称。每轮最多执行七次世界书工具查询；从第四次结果起向模型返回精确剩余次数，第七次结果说明限额已用尽，之后的模型推理移除世界书工具但不改变通用工具状态。世界书开关同时控制直接上下文和静默工具，输入区分别保留通用工具快捷开关与显示当前作品、进度的世界书菜单，避免两个开关在语义上互相覆盖。关系历史使用模型显式传入的页码、固定每页五条并按由新到旧返回，重复查询仍返回完整结果而不依赖模型记住隐式游标或去重占位信息。开发者诊断显示只改变检索过程的可见性，静默工具不产生过渡回复、语音或聊天历史消息；独立的本地滚动诊断记录遵循其自己的告知、保留和导出规则。新运行时检索以正式世界书模型为边界，不重新接入与其字段已经不一致的旧 RAG 集成类，旧文件留待稳定后单独清理。
