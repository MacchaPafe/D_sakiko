# 本机开发原型

本轮以 `7265f2a` 为工程与接口基线，验证单角色、编剧式二人对话、Agent Loop、语音合成、Live2D 演出、多对话后台推进和用户人格。交付目标是在本机通过 `pnpm dev` 启动，不制作安装包。本文限定本轮实现范围；核心模块的数据和调用约定仍见 `core-interfaces.md`。

## 范围与交互

- 使用 React、shadcn/ui，参考旧 WebUI 的浅色界面、角色头像与消息样式；提供聊天列表、舞台、消息、输入、新建对话、人格编辑与设置。
- 单角色或两名 AI 角色参与一份 Chat。双人由一次 Agent 执行生成有序台词，不实现相互无限续聊。
- 输入限文本。同一个 Chat 在生成、等待合成及演出期间不接受下一轮；可以编辑草稿和切换聊天。状态检查由 Conversation 负责。
- 生成的台词在首次发布时即带 `pending` 显示状态，等待演出期间不显示气泡、头像或占位文字；开始后原文和翻译随进度逐字出现。显示状态只属于运行态，已结束、主动停止或重启后的生成历史仍完整保留。
- 全应用只有一个前台 sequence。后台仍进行 Agent Loop 和合成，演出按时间推进，但不发声、不显示字幕、不更新 Live2D。队首未 ready 时等待；返回前台从当前未完成句开头播放，已完成句不重播。
- 停止使旧执行失效，保留已生成内容及正在演出的当前句，撤销后续演出与合成；迟到结果不能重新写入或播放。
- 人格支持自定义名称与描述，以及引用现有角色。创建 Chat 时固定身份，之后编辑人格或来源角色不改变旧 Chat。
- 角色装扮支持从共用角色目录中选择 v2/v3 模型，对该角色的全部 Chat 生效并独立保存。首次沿用旧配置或默认模型；保存后的选择优先于旧配置，文件缺失时明确提示，不自动换成其他模型。换装同时刷新展示及动作、表情清单，历史台词和语音不改写。
- 默认日语台词与语音、中文翻译，可在设置中改为中文。时间工具使用系统时区。默认模型连接采用 OpenAI 兼容的 Chat Completions 报文，自建有限 Agent Loop；工具只有当前时间，格式错误有限纠正，保留已执行工具结果。
- 意外退出后永久不自动恢复 Agent Loop、合成或演出。重启加载已保存内容，未完成工具记录标为中断，新轮可以正常开始。

## 通信与所有权

React 通过 runtime → preload → IPC 调用具名业务命令；主进程验证发送者和参数。跨进程只传普通数据，错误以 Problem 交付。Node 中的 Conversation 是 Chat 唯一修改者，修改与落盘串行化，运行态订阅与持久化版本分开。

Performance 常驻前端应用根部，不随聊天页或设置页卸载。Node 通过演出代理发送有编号的具名命令，前端返回回执、进度与终态。显示端断开时结束旧等待并使旧执行失效，不重放任务。主进程不负责逐句计时。

Python 是语音队列、优先级、执行槽和驻留模型的唯一所有者。Node 客户端仅转换请求、轮询与保存音频。多个隔离 worker 内部各自串行推理，执行槽和驻留上限独立配置；取消后的实际推理退出前仍占用预算。只淘汰空闲实例，同优先级默认 FIFO。默认预算保守，但实现和测试必须覆盖多个槽与多个驻留实例。

## 资源与独立性

代码和依赖位于本工程，不跨目录导入旧 WebUI 或父项目业务模块。必要的 Live2D 适配及 GPT-SoVITS 推理依赖复制到本工程并记录来源；原有角色管理、Qt 界面和全局配置不随之搬入。

初版通过显式设置外部资源根目录读取旧程序的角色、模型、参考音频和预训练权重，外部资源只读。不实现资源下载、资源编辑、自动回收、完整引用计数和迁移。轻量寻址模块将 AssetRef 转换为受控路径或桌面媒体地址；Chat 不存绝对路径和临时 URL。Live2D 模型及相对依赖作为资源包提供。

本工程的设置、聊天、人格和完成的语音使用独立可写数据目录。Python 临时输出导入持久音频目录后再交付业务；原型暂不自动删除持久音频。凭据不写入聊天、不提交到 Git、不回显到日志。

模型发现与偏好保存在 `characters/models.js`：只扫描共享目录，`character-models/` 中保存角色与相对入口对应的稳定身份。桌面命令 `setCharacterModel(characterId, modelId)` 只接受目录发现的身份，不接受任意文件路径。Conversation 把输入受理与配置修改串行化，防止发送尚未写入忙碌状态时换装穿透检查；只阻止涉及该角色的生成和演出，不等待其他角色的后台任务。空闲舞台随选择更新，当前历史回放在换装时结束，下一轮使用新模型的动作及表情能力。

暂缓：打包、桌宠、托盘驻留、手机访问、ASR、附件、远端文件、世界书、历史编辑/回溯/分叉、归档导入导出、服装下载、反馈、更新与修复。未实现入口不向 UI 开放，不使用空方法伪装成功。

## 验收

1. 本机启动真实 Electron，能够配置或导入本机运行配置、选择角色和人格、保存并重新打开聊天。
2. 模型通过时间工具完成至少一轮工具循环；非法台词经过有限格式纠正，失败有明确提示。
3. 单角色及二人回复按顺序交付台词、声音、动作和字幕，验证 v2/v3 混合同屏。
4. A 生成或演出时切到 B，A 继续推进且不发声；返回后不重播已完成句，忙碌期间不能重复发送。
5. 停止、合成乱序完成、语音失败、模型加载失败、旧回调到达均不会造成串话、重复完成或永久忙碌。
6. 调度测试覆盖两套常驻/一个执行槽、两套常驻/两个执行槽、优先级、取消后预算仍占用、仅淘汰空闲模型。
7. 人格更新不影响旧 Chat；重启保留完整已保存文本，旧任务不续跑。
8. 检查工程不依赖父仓库代码导入；真实外部服务或硬件验证缺失时明确记录，不以测试替身冒充实测。

### 已完成验证（2026-10-05）

- 12 项 JavaScript 测试：后台时钟、未 ready 队首、合成乱序、停止与迟到结果、请求去重、草稿、存档修订、人格快照、格式纠正/时间工具、旧配置导入与中断恢复。
- 7 项 Python 调度测试：双槽独占、常驻预算、优先级、取消不提前释放执行槽、失败隔离、参考音频更换时复用权重、结果续期。
- 4 项真实 Electron 端到端测试：受控 IPC、人格、二人对话、切换与后台推进、重启持久化、真实 v2/v3 同屏、真实双角色语音合成和整轮播放。模型文本响应由本机测试服务器提供；真实语音没有使用测试替身。
- 本机 CPU 上，小祥与爱音两个隔离 worker 并行合成成功；独立短句验收分别得到约 1.06 秒和 1.14 秒音频。完整界面验收也检查两句音频均持久保存、播放结束后恢复 idle。
- 自有 Python 文件通过 3.9 语法解析与编译检查；独立 `uv.lock` 成功解析。实际运行环境为 Python 3.11、macOS ARM64；尚未做 Python 3.9、Windows、CUDA/MPS 的完整推理验收。

用户明确授权后，已执行 `node scripts/verify-agent.mjs sakiko anon` 完成外部模型实测：使用旧配置中的 `https://api.deepseek.com`、`deepseek-flash`，输入祥子与爱音的角色设定、虚构测试人格和时间问候请求。Agent 状态为 `completed`，实际调用 1 次时间工具后返回两名角色各一句日语台词，结果通过原型的角色编号、文本及演出选择校验。脚本退出码为 0，临时数据已清理，凭据未输出。

本次实测确认了真实 DeepSeek 的接入与工具循环；格式错误纠正仍由确定性测试覆盖。前述真实语音与 Live2D 整轮界面验收使用本机模型响应服务器，两项验证分别记录，不将其描述为一次完整的外部模型到播放的端到端实测。

本次角色装扮迭代新增 4 项集成测试，共 16 项 JavaScript 测试通过，覆盖偏好独立持久化、旧配置不变、动作与表情清单更新、非法或缺失入口、后台生成/演出保护及发送受理与换装的竞态。真实 Electron 的 4 项本机测试通过，验证装扮面板中的 v3 → v2 → v3 切换、双人同屏及重启恢复；语音整轮测试本次跳过，外部模型服务没有重新调用。构建、lint 与格式检查通过，换装面板和两代模型舞台截图均已完成视觉检查。

演出布局回归：长对话曾通过外层 Grid 的自动最小高度撑高工作区，使消息区无法内部滚动，Live2D 又按被撑高的画布重排。修复明确了窗口与工作区的行高边界，允许内部容器收缩，并保留标题、输入框的高度；超长舞台字幕单独限高滚动。新增真实 Electron 回归用例，在十句台词演出中测量消息滚动、舞台与画布高度、输入框位置，并验证 860×640 与 1360×860 窗口。测试只使用本机响应服务器和临时存档。

回放与显示修复：Live2D 启动动作返回 false 或失败时，旧循环会立即重试，Promise 微任务可能持续占用渲染线程。现在直接跳过不可用动作，正常动作之间也让出事件循环；停止或切换播放时同步撤销计时器和监听，迟到结果不影响新回放。退出并行关闭对话与语音，正常清理后直接退出；渲染端故障时最长等待 12 秒，不再无限等待窗口关闭握手。

此轮共 22 项 JavaScript 测试、7 项真实 Electron 测试通过，覆盖等待台词隐藏、首次发布不闪现、逐字翻译、后台完成、动作被拒绝/异常/同步结束、播放取消、v2/v3 重复回放和故意阻塞渲染线程后的系统退出。音频回放使用真实媒体协议和静音 WAV，未重新运行语音合成或调用外部模型服务；构建、lint 与格式检查通过。

### 后续迭代保护

原型存档包裹 `schemaVersion: 1`，与保存修订号及运行态修订号分开；协议只传普通数据和稳定引用。复制的推理依赖位于 `python/vendor/`，外部资源布局适配集中在目录模块，后续可分别替换 UI、模型连接、推理库或资源管理而不改写聊天所有权规则。

已有 Git 基线不变。本轮不自动提交或推送；可审查后单独提交这一轮实现。后续正式重构不应将临时原型设置格式、旧目录布局或测试服务器当成长期接口。
