# 资源下载器客户端

入口仍为 `GPT_SoVITS/live2d_downloader_ui.py`。新模块集中在 `live2d_download/hosted/`；父目录原 Bestdori 服务保留。

| 文件 | 职责 |
| --- | --- |
| `catalog.py` | 12 队和 Others 的成员顺序、不可变选择状态、保存位置 |
| `service.py` | 自有 Worker 目录、预览、流式下载及 SHA-256 校验 |
| `legacy.py` | 调用旧 Bestdori 下载器和 `AddCostume` 安装器 |
| `jobs.py` | 主线程信号、取消事件和有界线程池 |
| `ui.py` | 顶部资源导航、角色卡片、版本分栏和图片画廊 |

## 当前行为

- V2 继续下载后安装。独立入口固定工作目录为 `GPT_SoVITS`，以兼容旧安装器的相对路径；直接嵌入其他进程时也需满足这个前提。
- V3 只下载 ZIP，不解包或创建本地角色。原型 ZIP 保存在项目 `GPT_SoVITS/.model_download_cache/hosted/` 下的会话目录，完成后可打开位置。当前阶段保留 ZIP，后续接入安装时再改为退出自动清理完整包。
- 背景保存到项目根目录 `live2d_related/`；聊天头像保存到 `GPT_SoVITS/assets/char_headprof/webui_chat_mode_avatars/<romaji>/`。WebUI 多头像选择及绑定尚未实现。
- 下载串行；下载、取消及安装尚未结束时禁止返回、刷新和启动其他下载。关闭窗口会取消并等待后台任务完成，不强制终止线程。
- 写入随机 `.part` 文件，完整性检查通过后才发布。图片遇同名文件先弹窗确认，再原子替换，失败保留原文件；模型 ZIP 同名另存。失败和取消删除本次 `.part`。
- V3 读取目录接口返回的 `sha256` 并边下载边计算。摘要为空时允许下载，但明确显示未提供校验值。
- 预览按可见条目加载；立绘预取当前角色及相邻两人。磁盘缓存六小时过期，点击图片可打开原图预览窗口。
- 旧 V2 下载完成后安装阶段不可回滚；此时关闭窗口会等待安装退出。V2 安装失败仍沿用旧安装器语义，不承诺事务回滚。

## 凭证与发行

自有域名固定为 `https://models.dsakiko.org`。请求使用 `D-Sakiko-Downloader/2.0` User-Agent，拒绝重定向，Token 不发给 Bestdori。

本机静态下载 Token 已配置到 `_credentials.py` 的 `DOWNLOAD_TOKEN` 常量，该文件被 Git 忽略。私有发行包需包含此文件；也可通过 `DSAKIKO_DOWNLOAD_TOKEN` 环境变量覆盖。不要把 R2 上传密钥或 Cloudflare 管理令牌放入客户端。缺少凭证时界面显示配置错误，不会自动开放请求。

## 验证

`GPT_SoVITS/test/test_resource_downloader.py` 包含服务、Qt 生命周期和 V2 衔接回归；使用项目运行环境执行，Qt 可离屏运行。测试不会安装真实模型。

`下载器v2迭代/probe_client_service.py` 使用实际客户端服务读取云端目录、下载三类样本并校验 ZIP；结果在 `client-service-test.json`。该脚本需要本地已配置下载凭证，不修改云端数据。

### 角色卡片视觉与交互（2026-09-29）

沿用 `dialogWindowDefaultCss` 的背景、按钮和状态颜色。窗口、字体、布局间距按 Qt 当前屏幕的可用逻辑分辨率换算；切换显示器时重新计算，不额外乘 Windows DPI 比例。

卡片展示中文全名、日文名、角色主题底色、右侧放大立绘，以及左下的乐队名与担当。中部保留留白，不展示成员序号；担当由 `catalog.py` 的 `CHARACTER_ROLES` 按角色标识维护，未确认的配角暂不显示。

拖动跟手，松手滑动吸附；左右按钮也使用 320 毫秒缓出动画，并连续调整中心卡片大小。动画完成后才提交角色选择，期间禁用进入资源页；更换乐队取消旧动画。

本轮通过 16 项无网络回归测试，包含动画中间帧、完成提交、换组取消。离屏检查了 1280×720、1920×1080、2560×1440 的逻辑分辨率布局；真实 Windows 多屏与 125%/150% 缩放仍需交互验收。

### 卡牌视觉细化（2026-09-29）

仅调整绘制和样式，保留加载、下载、角色切换及动画状态逻辑。角色卡片使用低饱和纵向渐变、极淡斜纹、底部融合色雾及圆角投影；侧卡统一约 60% 透明度并略微缩小下沉，暂保留姓名和乐队文字。中文名增加字重和字间距，副标题使用半透明白字；乐队与担当改为深色胶囊。两行队徽增加统一底板、选中识别色和按压态；底部改为左侧弱化返回、右侧限宽主按钮。尺寸继续使用现有屏幕比例换算。

### 拖拽修复与乐队背景（2026-09-29）

鼠标拖动位移与 QVariantAnimation 两个端点统一为浮点数，替换端点时屏蔽中间信号，并防御空动画值。新增左右拖动、反向切换及短距离回弹回归。日文名按实际渐变顶部亮度使用深墨色或淡蓝白；所有立绘统一生成缓存轮廓投影。窗口背景以 380 毫秒过渡到淡化乐队色，快速切换从当前颜色继续，不在帧回调中设置样式表或布局。新增背景重定向测试，目前 18 项回归通过。

### 项目缓存与窗口行为修订（2026-09-29）

托管资源预览和临时模型 ZIP 统一缓存到 `GPT_SoVITS/.model_download_cache/hosted/` 下的 `resource-previews/`、`resource-downloads/`，不再使用系统用户缓存目录。此前已生成的 C 盘缓存未自动删除。人物淡入按角色独立管理，网络、磁盘缓存、内存缓存展示均适用，中心和左右卡片均淡入。1560×1200 仅作为用户屏幕上的初始物理尺寸按比例换算，允许拖动边框调整大小。新增缓存淡入和窗口缩放回归，目前 20 项测试通过。

### 图片网格与分页（2026-09-29）

背景和头像使用独立的图片网格布局，每页 24 张，按窗口宽度自动换行；搜索作用于完整目录，长名称中间省略并提供完整悬停提示。当前使用客户端分页：Worker 仍一次返回目录元数据，客户端只创建当前页控件，并按可见区域请求缩略图。翻页使旧预览回调失效，下载中禁用翻页和搜索；成功下载状态在本次窗口内跨页保留。

修复 ResourceRow 预览 QLabel 无父控件时提前显示导致的顶层小窗口闪烁。资源条目及预览标签构造时即设置父控件。新增 55 条目录翻页、全局搜索与顶层窗口显示事件回归，目前 23 项通过。

后续服务端分页可在 `/api/images` 增加 page/page_size/q 参数和参数化 SQL 的 LIMIT/OFFSET、同条件 COUNT 查询；维持现有表结构，不向客户端开放 SQL。当前未修改或部署 Worker。

### 常驻顶部导航（2026-09-29）

移除四入口首页，默认直接进入角色模型选择。顶部左侧为“下载资源类型”和角色模型、聊天头像、背景图片三个文字页签；右侧在模型模式下显示下载新角色／为已有角色添加服装，使用浅色文字与细下划线区分选中态。

跨类型保留当前乐队和来源角色；已有角色模式额外显示接收角色下拉框，未选目标仍可浏览但不可进入模型列表。背景直达分页网格，头像通过选定角色进入分页网格。资源页返回角色选择，不再返回首页。下载期间锁定顶部导航。原卡片绘制及轮播保持不变，当前 25 项回归通过。

## 界面与兼容性

- 默认进入角色选择页，顶部切换模型、聊天头像、背景图片；名称筛选暂时停用。
- 图片每页 24 张、每行四列，按窗口宽度居中布局；默认隐藏文件名，尺寸经 ScreenMetrics 按屏幕比例换算。
- 原图预览可关闭或按 Escape 取消加载，图片下载支持同名覆盖确认。
- V2 新角色在下载前及安装前检查目录是否存在，界面同时检查包内角色名称。
- 使用 Python 3.9.13 验证启动依赖，避免 dataclass(slots=True)、运行时 PEP 604 类型别名和不受支持的标准库入参。
